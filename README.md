# Jayant Sen — Developer Portfolio Website

A modern, minimal, futuristic developer portfolio website engineered for **Jayant Sen**, 1st Year B.Tech Computer Science & Engineering undergraduate at JECRC University, Rajasthan, India.

---

## 🌟 Highlights & Design Features

- **Dark, Futuristic Aesthetic**: Custom dark palette (`#040711`), ambient neon gradients (Cyan `#00f2fe`, Violet `#8b5cf6`, Emerald `#10b981`), glassmorphic panels, and a developer-centric subtle grid pattern.
- **Dynamic Terminal Component**: Hero section includes an interactive C code simulation (`jayant_profile.c`) styled with realistic syntax highlighting and window controls.
- **Micro-Interactions & Animations**:
  - Ambient mouse cursor spotlight tracker
  - Dynamic typewriter subtitle cycling through genuine student focuses
  - Scroll-triggered reveal animations via `IntersectionObserver`
  - Active navigation tracking and sticky blurred glass navbar
  - Interactive project detail modal cards with architectural breakdowns
  - Instant one-click "Copy Email" with visual feedback and custom toast notifications
- **100% Genuine & Authentic**: Zero fake metrics, zero exaggerated years of experience, zero fabricated certifications. Accurately highlights academic foundations, C programming logic, and practical campus utilities.
- **Fully Responsive**: Mobile-first architecture with custom sliding drawer navigation, tailored breakpoint styling, and touch-friendly controls.
- **Zero Heavy Dependencies**: Pure semantic HTML5, modern CSS3, and vanilla JavaScript—loads instantly with 60fps responsiveness and zero bloatware.

## 🚀 How to Run & Preview

1. **Direct Double-Click**:
   - Simply double-click `index.html` in your file explorer to launch the portfolio directly in any web browser (Chrome, Edge, Firefox, Brave, Safari).

2. **Using VS Code / Antigravity Live Server**:
   - Right-click `index.html` and click **"Open with Live Server"** (if the extension is installed) or open with any local static HTTP server.
